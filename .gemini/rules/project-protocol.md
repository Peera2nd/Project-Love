# Project Love — Shared Agent Rules

Follow [AGENTS.md](../../AGENTS.md), the canonical operating protocol.

1. Read in order: Mistakes Registry -> latest Handoff -> Architecture -> Master Decisions, then Task Board and task-specific files.
2. Use concise English for backend design/technical documents, tasks, handoffs, logs, incident records, and internal comments. Use Thai for user interaction and narrative/character documents under `Docs/02_Narrative_And_World/`. Existing machine-facing prompts may remain English; artist-facing tooltips and game text remain Thai-friendly.
3. The approved full playthrough lasts **30 in-game days**. Use configurable data and allow emotional buildup and recovery from routine mistakes. Do not revert to the historical 14-day draft or mark duration as undecided.
4. Put owned assets in `Project Love/Assets/_Project/`. Preserve `.meta`/GUID pairs, separate runtime/Editor code and static/runtime data, and expose content through data and Editor tools.
5. Approval: Master Decisions. Implementation: Task Board plus actual files. Character wounds: profile section 5. Data names: Data Architecture. Expressions: Art Pipeline. Historical logs do not override current decisions.
6. Before finishing, update Task Board and Handoff, record encountered issues, and state verification limits. Do not claim implementation or successful tests from documentation alone.
