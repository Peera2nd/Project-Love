# 05 — ไอเดียอีเว้นสำหรับการเล่นครั้งแรก

Session 056, 2026-10-25 — ข้อเสนอฉากและจังหวะเรื่อง ยังไม่ใช่บทอนุมัติหรือเนื้อหาที่ใส่ในเกม

อัปเดต Session 059: เจ้าของอนุญาตให้ทำช่วงเปิดนี้แล้ว ใส่บททดลองในแคมเปญ Romance ด้วยระบบเดิม ดู [วิธีเล่นและแก้บท](06_Opening_Story_Play_And_Authoring_Guide.md) ข้อเสนอขยายสัปดาห์/รายละเอียดปมใหญ่ในเอกสารนี้ยังไม่ใช่เนื้อหาอนุมัติทั้งหมด

เจ้าของขอพักงานเกมเพลย์ Producer และโฟกัสความสนุกจากอีเว้นเนื้อเรื่อง ใช้ฉากห้องและระบบบทพูด/อีเว้นที่มีอยู่เป็นฐาน เป้าหมายของช่วงเปิดคือผู้เล่นเห็นเคมีทีม อยากคุยกับใครบางคน และมีเรื่องเล็กให้ตั้งตารอวันถัดไป

ปมปลายฟ้ามีหลายทางเลือกที่ยังพิจารณาอยู่ใน [ข้อเสนอล่าสุด](Research_References/05_Synthesis_And_Project_Love_Story_Proposals.md) ฉากด้านล่างจึงเน้นความขี้อาย ความสามารถ และการเริ่มคุยกัน ไม่ล็อกสาเหตุอดีตหรือจุดพีค ไม่ใช้ปมศิลปินเกลียดงานตามบรีฟ/อึดอัดเพราะงานไร้ความรักที่เจ้าของวิจารณ์แล้ว

## 1. ฉากเปิด: “สารภาพรัก หรือสมัครงาน”

Producer มาถึงตอนทีมกำลังทดลองฉากสารภาพรักในเกม มีฉากร่างที่ยังไม่สื่ออารมณ์ตรงกัน แต่ละคนเห็นปัญหาต่างกัน เกรซอยากให้เจตนาชัด พลอยอยากให้คนเล่นมีส่วนตอบ ปลายฟ้ามองว่าควรเว้นจังหวะให้สีหน้าเล่าเรื่อง ผู้เล่นได้ช่วยทดลองทันที

ตัวอย่างโทนบทสั้น ไม่ใช่ประโยคล็อก:

> เกรซอ่าน: “ผมอยากให้คุณพิจารณาความสัมพันธ์ระยะยาวกับผม”  
> พลอย: “นี่ขอเป็นแฟน หรือรับสมัครพนักงานคะ?”  
> ปลายฟ้า: “...ถ้าใช้ประโยคนี้ ฟ้าต้องวาดเขาถือแฟ้มด้วยไหมคะ”  
> เกรซ: “บอกแล้วไงคะว่าประโยคชั่วคราว”

ความขำมาจากคนเก่งงานที่มีมุมเปิ่นในเรื่องรัก ไม่ใช่ทุกคนทำงานไม่เป็น ผู้เล่นเลือกว่าจะลองให้ตัวละครพูดตรงขึ้น เว้นจังหวะให้คนฟังตอบ หรือเปลี่ยนสถานการณ์ให้เป็นธรรมชาติก่อน ไม่มีการประกาศว่าคำตอบใดได้หัวใจสูงที่สุด ฉากจบด้วยชิ้นงานเล็กที่เปลี่ยนตามสิ่งที่เราเสนอ

## 2. เลือกอยู่ต่อกับใคร แล้วเห็นอีกด้านหนึ่ง

หลังฉากรวม เปิดห้องให้เลือกคุยได้ อีเว้นสั้นของแต่ละคนเป็นคำเชิญให้รู้จักต่อ ไม่เปิดปมใหญ่พร้อมกันทั้งหมด

| คน | เหตุการณ์สั้น | สิ่งที่อยากให้ผู้เล่นรู้สึก |
| --- | --- | --- |
| ปลายฟ้า | ชวนไปซื้อของว่างด้วยข้อความที่จัดระเบียบเหมือนบรีฟ พอถูกถามว่าทำไมต้องมีหัวข้อ เธอยอมรับว่าไม่รู้จะเริ่มชวนอย่างไร | เธอดูเข้าหายากแต่พยายามเข้าหาเราเอง และมีมุกเบาๆ ของตน |
| เกรซ | ชวนอ่านบทสองแบบ เมื่อผู้เล่นเลือกแบบที่เธอเขียนเอง เธอถามเหตุผลละเอียดเกินงานตรวจบั๊กเล็กน้อย ก่อนเลี่ยงไปเปิดไฟล์ทดสอบ | คนที่ดูมั่นใจสนใจว่าเราคิดอย่างไร โดยยังไม่ต้องสารภาพว่าชอบอะไร |
| พลอย | ชวนซ้อมบทเล่นๆ พร้อมกำชับว่าห้ามนอกบท ผู้เล่นเลือกเล่นจริงจัง แซวกลับ หรือขอดูก่อน พอเธอตั้งตัวไม่ทันก็ขอเริ่มใหม่ด้วยกติกาที่แก้เอง | เธอรับมุกและปรับตัวได้ ไม่ใช่คนแซวแล้วไม่มีวันเสียอาการ |

ทุกทางมีฉากที่คุ้มค่าและอยู่บนความสมัครใจ การเลือกคนหนึ่งครั้งนี้ไม่ประกาศล็อกเส้นรัก และไม่บังคับให้ไล่เก็บอีเว้นทั้งสามในวันเดียว

## 3. วันถัดมาต้องมีอะไรจำเราได้

เลือกทำผลตอบกลับเล็กๆ ที่สังเกตได้ทันที เช่น เกรซใช้วิธีพูดที่เราช่วยเลือก พลอยยกมุกเมื่อวานมาล้อ หรือปลายฟ้าส่งคำชวนที่สั้นลงเพราะเราเคยบอกว่าไม่ต้องเป็นทางการ การตอบสนองต่างกันตามสิ่งที่เกิดจริง แทนการใช้บทขอบคุณเหมือนกันทุกทาง

หนึ่งผลตอบกลับก็พอให้ผู้เล่นเริ่มคาดหวังว่าวันต่อไปจะมีเรื่องต่อ ตัวอย่างนี้ออกแบบให้ใช้บทพูด/สีหน้าก่อน จึงไม่ต้องรอ CG หรือฉากใหม่

## 4. มีนัดเล็กๆ และได้เห็นผลตั้งแต่ต้นเกม

ช่วงวันที่ 2 ตัวละครที่เราใช้เวลาด้วยชวนทำบางอย่างในวันที่ 3 เช่น ดูฉากที่ช่วยแก้ฉบับใหม่ ซื้อของว่างร้านเดิม หรือทดสอบบอร์ดเกมหลังเลิกงาน ผู้เล่นรับ ปฏิเสธ หรือเสนอเวลาที่สะดวกได้ โดยรู้ก่อนว่านัดใช้ช่วงเวลาไหน

วันที่ 3 ให้มีฉากตอบแทนจริง: คำถามหนึ่งที่ไม่ได้เกี่ยวกับงาน มุกที่คุยกันรู้เรื่องสองคน หรือจังหวะที่ตัวละครชวนเราก่อน การพลาดนัดมีฉากรับผิดชอบ/โอกาสชวนใหม่ที่เหมาะสม ไม่ตัดเส้นเรื่องเงียบๆ และไม่ทำให้การเลื่อนเวลาได้ผลประโยชน์ทุกอย่างเสมอ

## 5. ปิดสัปดาห์ด้วยเดโมที่มีร่องรอยของเรา

เสนอฉากทีมทดลองเดโมฉบับแรกด้วยกัน ประโยคหรือจังหวะจากฉากเปิดกลับมาในเวอร์ชันที่เปลี่ยนไปตามการเลือก คนในทีมจำได้ว่าใครเป็นคนเสนอ และมีผลตอบกลับส่วนตัวสั้นๆ ตามเหตุการณ์ที่เล่นมา จากนั้นทิ้งคำชวนหรือคำถามใหม่เพียงเรื่องเดียวให้ตั้งตารอสัปดาห์ถัดไป

ความตื่นเต้นของสัปดาห์นี้มาจากการได้รู้จักคนมากขึ้นและเห็นเรื่องที่ร่วมทำสำเร็จ มีอารมณ์ขัน ความเก้อเขิน และการเลือกที่ทิ้งร่องรอยก่อนเพิ่มวิกฤตใหญ่

## ขอบเขตต้นแบบที่แนะนำ

เริ่มจากวันที่ 1–3: ฉากเปิดกลุ่มหนึ่งฉาก → เลือกฉากส่วนตัวหนึ่งคน → วันถัดมาเห็นผล → นัดและฉากตอบแทนหนึ่งครั้ง หากโทนและจังหวะใช้ได้จึงขยายฉากเดโมวันที่ 7 และเพิ่มทางเลือกอีกสองคน ใช้เหตุการณ์ที่มีเงื่อนไขแน่นอนสำหรับชุดนี้ ไม่พึ่งระบบสุ่ม Producer ที่พักไว้

ข้อควรดูตอนลอง: ผู้เล่นจำเหตุการณ์แรกได้ไหม อยากคุยกับใครและเพราะอะไร รู้ว่าพรุ่งนี้มีเรื่องอะไร และเห็นว่าตัวละครจำการเลือกของตนได้หรือไม่ นี่ยังเป็นเป้าหมายการลอง ไม่ใช่ผลทดสอบแล้ว
