# ฉากต้นแบบ: อาสาอยู่ดึกและทำงานด้วยกัน

Session 032 — บททดลองระบบ ยังไม่ใช่บทเนื้อเรื่องหรือ Personal Arc ฉบับอนุมัติ

ฉากเกิดจากงานที่พร้อมทำและใกล้วันส่งจริง ตัวละครอาสาผ่านบับเบิล ผู้เล่นเลือกอยู่ช่วย ให้อยู่ต่อ หรือให้พักได้ การปฏิเสธไม่มีโทษความสัมพันธ์ และการอยู่ดึกไม่ใช่เงื่อนไขบังคับของเส้นทางรัก

| ตัวละคร | แนวเสียงในคำชวน/ฉากร่วมงาน | ด้านที่เปิดเผยเมื่อสนิทหรือเหนื่อย |
| --- | --- | --- |
| เกรซ | สุขุม ระบุขอบเขตงาน ไม่ข้ามเงื่อนไขที่ยังไม่พร้อม | ยอมรับว่าคิดไม่ออกหรือกำลังฝืน ขอบคุณคนที่ช่วยให้ยอมหยุด |
| ปลายฟ้า | สุภาพ เกรงใจ อยากมีคนช่วยดูงาน | การมีคนอยู่ข้างๆ ลดการคิดวน ไม่ต้องเก็บงานเงียบๆ คนเดียว |
| พลอย | ชวนเป็นคู่คิด ใช้มุกเบาๆ แต่ยังสนใจคุณภาพงาน | ยอมบอกว่าเหนื่อย และเป็นฝ่ายได้รับการช่วยเหลือบ้าง |

แต่ละคนมีคำชวน/ฉากช่วยงาน 4 แบบ ตามความสนิทต่ำ–สูงและความเครียดต่ำ–สูง การทำงานร่วมกันเชื่อมการ์ดงานจริง ไม่ประกาศว่างานทั้งหมดสำเร็จหรือส่งแล้ว หลังทำงานต้องตรวจรับบนบอร์ดตามปกติ

เช้าวันถัดไปที่มีโอกาส จะมีบทระลึกถึงคืนที่ช่วยกัน 2 แบบตามความสนิท เลือกได้เพียงแบบเดียวต่อคนเมื่อเล่นจบ บทนี้ไม่ให้คะแนนซ้ำ การย้อนออกไม่ถือว่าดูจบ

บททั้งหมดอยู่ใน `StudioNightSeed.json` สำหรับตั้งต้น และ `Data/Studio/Events/` สำหรับแก้ต่อผ่าน Inspector รายละเอียดค่าทดลองและวิธีทดสอบอยู่ใน [คู่มือระบบ](../04_Technical_And_Tools/05_Studio_Night_Work_Guide.md) ไม่มีอีเว้นป่วย บทสารภาพรัก หรือการล็อคเส้นทางเพิ่มในรอบนี้
