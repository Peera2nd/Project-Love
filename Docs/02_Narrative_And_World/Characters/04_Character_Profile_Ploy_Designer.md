## 🎨 หมวดที่ 2: รูปลักษณ์ภายนอกและการแต่งกาย (Visual Appearance & Silhouette)

### 2.1 โครงสร้างใบหน้าและทรงผม
- **สีผม:** น้ำตาลคาราเมลสว่าง (Warm Caramel Brown) มีประกายทองเวลาโดนแสงไฟ
- **ทรงผม:** ผมดัดลอนคลายยาวประบ่า (Wavy Shoulder-length) มักมัดเป็นทรงหางม้าข้างแบบหลวมๆ (Side Ponytail) หรือทวินเทลมัดต่ำ มีปอยผมด้านบนชี้กระดิกตามอารมณ์คล้ายเสาอากาศ (Ahoge) ที่ดุ๊กดิ๊กเวลาเธอตื่นเต้นกับไอเดียใหม่ๆ
- **สีตา:** สีน้ำตาลฮาเซลประกายทอง (Sparkling Hazel-Gold) สดใส กลมโต ขี้เล่น แววตาเต็มไปด้วยประกายความซุกซนและอยากรู้อยากเห็น
- **รูปตาและบรรยากาศใบหน้า:** ตากลมโตแบบเปิดกว้าง (Cat-eyed / Expressive) รอยยิ้มกว้างสดใสเห็น **เขี้ยวเสน่ห์ซี่เล็กๆ (Cute Little Fang)** ที่มุมปากด้านซ้าย
- **จุดดึงดูดสายตาบนใบหน้า (Facial Charm Point):**
  - **เขี้ยวเสน่ห์มุมปาก:** โผล่ออกมาทุกครั้งเวลาเธอยิ้มกว้าง หัวเราะ หรือแลบลิ้นแซวพระเอก
  - **การแสดงออกทางสีหน้าที่เปลี่ยนไปมาเร็วมาก (Hyper-Expressive):** ยิ้มตาหยี, ทำแก้มป่อง, หรือแลบลิ้นแกล้งคนอื่นได้อย่างเป็นธรรมชาติ

### 2.2 รูปร่างและสัดส่วนร่างกาย
- **ส่วนสูง / น้ำหนัก:** 160 ซม. / 47 กก.
- **รูปร่างและสัดส่วน:** รูปร่างสมส่วน คล่องแคล่ว ปราดเปรียว มีทรวดทรงเอวคอดแบบสาวนักกิจกรรม แขนขาเรียวกระชับ มีเสน่ห์สดใสแบบสปอร์ตตี้
- **จุดดึงดูดสายตาทางร่างกาย (Visual Hook / Fetish Point):**
  - **เอวคอดและสะดือสวย:** เวลาใส่เสื้อครอปแล้วเธอบิดตัวหรือเอื้อมมือหยิบของ จะเห็นแนวกล้ามท้องเพรียวบางและเอวคอดขาวเนียน
  - **เรียวขาและต้นขา:** สวมกางเกงขาสั้นยีนส์โชว์เรียวขาขาวผ่อง ดูทะมัดทะแมงและดึงดูดสายตา

### 2.3 การแต่งกายและภาษากาย
- **สไตล์แฟชั่นหลัก (Street Chic / Colorful Casual):**
  - สวมเสื้อยืดครอปท็อปสีพาสเทลสดใส (เช่น เหลืองมัสตาร์ด, ส้มพีช หรือฟ้าคราม) คลุมทับด้วยแจ็กเก็ตยีนส์ตัวหลวม แมตช์กับกางเกงขาสั้นยีนส์ชายรุ่ย หรือกระโปรงเทนนิส และรองเท้าผ้าใบสนีกเกอร์แฟชั่นสีขาวแต่งแถบสีสดใส
- **เครื่องประดับประจำตัว:** สร้อยข้อมือลูกปัดหลากสีแฮนด์เมด, ป้ายพนักงานห้อยคอสายลวดลายอนิเมะพร้อมพวงกุญแจลูกเต๋า 20 หน้า (D20), และเป้สะพายหลังใบโปรดที่อัดแน่นไปด้วยการ์ดเกมและสมุดโน้ตไอเดีย
- **ภาษากายประจำตัว (Micro-Expressions):**
  - *เวลาตื่นเต้น/มีไอเดีย:* ดีดนิ้วดังเป๊าะ กระโดดเกาะไหล่พระเอก หรือเอาหน้าเข้ามาใกล้จนสัมผัสได้ถึงลมหายใจ
  - *เวลาแกล้งแซว:* หรี่ตาลง เอียงคอ ยิ้มมุมปากโชว์เขี้ยว แล้วเอานิ้วจิ้มแก้มหรือสีข้างของพระเอก
  - *เวลาแอบกังวล/เครียดจัด:* กัดเล็บนิ้วโป้งเบาๆ นั่งกอดเข่าโยกตัวไปมา และรอยยิ้มจะเริ่มกระตุกฝืนๆ

## 🎭 หมวดที่ 3: อุปนิสัย มิติความต่าง และรสนิยม (Personality, Gap Moe & Preferences)

| มิติของนิสัย | รายละเอียด |
| :--- | :--- |
| **1. นิสัยปกติ (Everyday Personality)** | สดใส ร่าเริง เฮฮาและพลังเยอะอย่างเป็นธรรมชาติ ชอบตั้งคำถามและรับส่งความคิด ไม่ต้องเป็นคนสร้างความสนุกทุกนาที ความสนุกที่สุดมักเป็นการคุยหัวข้อที่ชอบกับคนสนิท ไม่จำเป็นต้องอยู่กลางปาร์ตี้คนเยอะ |
| **2. อีกมุมเมื่อสนิท (When Comfortable)** | ยังเป็นคนขี้เล่นคนเดิม มีความกังวลและเหนื่อยได้เหมือนคนอื่น บางวันอยากฟังอีกฝ่ายเล่าหรือนั่งเงียบด้วยกัน ความอ่อนแอไม่หักล้างความสุขก่อนหน้า และไม่ต้องเปลี่ยนบุคลิกหรือร้องไห้หนักเพื่อยืนยันความไว้ใจ |
| **3. เสน่ห์ความย้อนแย้ง (Gap Moe)** | - **ชอบหยอกมุกทะลึ่งแต่พอโดนเอาจริงกลับเป็นลูกไก่ในกำมือ:** ชอบแซวเรื่องสองแง่สองง่ามใส่พระเอก ทำเป็นผู้เชี่ยวชาญเรื่องความรัก แต่พอพระเอกจับทางได้แล้วรุกกลับแบบถึงเนื้อถึงตัว เธอจะหน้าแดงแจ๋ ตัวแข็งทื่อ พูดติดอ่าง และเขินจนมุดใต้โต๊ะหนี!<br>- **นักคิดเชิงระบบที่จริงจังเรื่องเกมเพลย์:** ภายใต้ท่าทางทีเล่นทีจริง เวลาเธอเปิดชีท Excel คำนวณสมดุลเกมหรือออกแบบ Rulebook เธอจะมีสมาธิและมีเหตุผลที่เฉียบคมมากจนทุกคนต้องยอมรับ |
| **4. จุดแข็ง (Strengths)** | - ความคิดสร้างสรรค์ล้นพ้น (Brainstorming เครื่องจักรผลิตไอเดีย)<br>- ความสามารถในการสังเกตพฤติกรรมผู้เล่นและความเข้าใจความสนุก (Player Experience)<br>- การสร้างขวัญกำลังใจและละลายพฤติกรรมในทีม (Morale Booster) |
| **5. จุดอ่อน (Weaknesses)** | - **ชอบยัดฟีเจอร์เกินตัว (Scope Creep):** มีไอเดียใหม่ทุก 5 นาทีจนงานตัวเองล้นมือและทำไม่ทัน<br>- **ข่มความรู้สึกเก่งเกินไป:** เวลาเศร้าหรือกังวล จะไม่ยอมพูดออกมา แต่จะยิ่งฝืนหัวเราะเสียงดังขึ้นจนคนอื่นดูไม่ออก |
| **6. สิ่งที่ชอบ (Likes)** | - **อาหาร/เครื่องดื่ม:** ชานมไข่มุกหวาน 100%, พิซซ่าหน้าชีสเยิ้มๆ, ขนมขบเคี้ยวรสสไปซี่, เครื่องดื่มผลไม้โซดา<br>- **กิจกรรม:** บอร์ดเกมแนวบลัฟฟิ่ง, ต่อตัวต่อเลโก้, เกมคอนโซล, ดูดวงและไพ่ทาโร่<br>- **ความสนิท:** คนที่สนุกกับการถกคำถามประหลาดและต่อยอดกันหลายตา เช่น หมูป่าในเกมหาเงินที่ดรอปมาจากไหน คนที่รับฟังวันที่เธอเหนื่อยโดยไม่บังคับให้เฮฮาหรือเปิดปม |

## 🧠 หมวดที่ 4: โครงสร้างจิตวิทยาเชิงลึก (Psychological Profile & AI Inference Engine)

### 4.1 พิมพ์เขียวบุคลิกภาพ (Personality Typology)
- **MBTI Type:** **ENTP (The Visionary / Debater & Innovator — Ne-Ti-Fe-Si)**
  - *Dominant (`Ne` - Extraverted Intuition):* เชื่อมโยงไอเดียที่ดูไม่เกี่ยวข้องกันเข้าด้วยกัน มองเห็นความเป็นไปได้ใหม่ๆ ตลอดเวลา ชอบการระดมสมองและการทดลอง
  - *Auxiliary (`Ti` - Introverted Thinking):* วิเคราะห์โครงสร้างกลไกเกม กฎเกณฑ์ และความสมดุลด้วยตรรกะภายในที่เฉียบขาด แม้ภายนอกจะดูเหมือนเล่นๆ
  - *Tertiary (`Fe` - Extraverted Feeling):* ไวต่อบรรยากาศของกลุ่มอย่างยิ่ง เธออ่านใจคนในทีมออกว่าใครกำลังเครียด จึงใช้มุกตลกเพื่อปรับอารมณ์ทุกคน
  - *Inferior (`Si` - Introverted Sensing):* จุดอ่อนด้านการทำงานเอกสารซ้ำซาก ความทรงจำในอดีตที่เคยถูกปฏิเสธเป็นตราบาปที่เธอมักพยายามวิ่งหนี
- **Enneagram (นพลักษณ์):** **7w6 (The Entertainer / The Enthusiast with Loyalist Wing)**
  - *Instinctual Variant:* **`so/sx` (Social / Sexual)** — ใช้พลังแห่งความสนุกสนานเชื่อมโยงผู้คน คอยสร้างเสียงหัวเราะให้สังคม แต่โหยหาความสัมพันธ์แบบลึกซึ้งที่มีประกายไฟโรแมนติก
  - *Core Desire:* ความสุข ความตื่นเต้น และการได้รับการยอมรับในคุณค่าของสิ่งที่เธอรัก
  - *Core Fear:* ความเจ็บปวด ความล้มเหลว การถูกจำกัดขอบเขต และการถูกตีตราว่า "ไม่มีอนาคต"
