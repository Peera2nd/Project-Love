# 📋 Master Character Design Template (แม่แบบเอกสารออกแบบตัวละครเกมจีบสาวฉบับสมบูรณ์)

> **💡 คำแนะนำการใช้งาน (How to Use This Template):**
> **บทบาท:** แม่แบบหลักสำหรับโปรไฟล์ 9 หมวด; ใช้ `TEMPLATE_Character_Profile.md` เฉพาะร่างไอเดียแบบย่อ
> **สถานะเมื่อนำไปใช้:** WORKING DRAFT จนเจ้าของอนุมัติ; การกรอกครบและมี prompts ไม่ใช่ content lock รอบเกม 30 วันอนุมัติแล้ว ส่วนตัวเลขสมดุล/วันอีเวนต์/CG เป็นข้อเสนอจนผ่านการทดสอบตาม [Master Decisions](../../01_Game_Design/00_Master_Vision_And_Decisions.md)
> 1. **คุณไม่จำเป็นต้องกรอกครบทุกช่องด้วยตัวเอง:** กรอกเฉพาะส่วนที่คุณมีไอเดียชัดเจน (เช่น กรอกแค่นิสัยคร่าวๆ สีผม หรือตัวอย่างบทพูดไม่กี่ประโยค)
> 2. **การสั่งให้ AI Agent ช่วยคิดต่อ:**
>    - หากเว้นช่อง `MBTI / Enneagram` ไว้ -> Agent จะวิเคราะห์จากนิสัย/บทพูด แล้วคำนวณ **เปอร์เซ็นต์ความน่าจะเป็น (Probability %)** 3 อันดับแรกพร้อมเหตุผลให้คุณเลือก
>    - หากกรอก `MBTI / Enneagram / ปมในอดีต` ไว้ แต่เว้นช่อง `ตัวอย่างบทพูด` -> Agent จะเขียนบทพูดทั้ง 7 สถานการณ์ให้ตรงกับจิตวิทยาของตัวละครโดยอัตโนมัติ
>    - **หมวดที่ 9 (Prompts ทั้ง 3 ด้าน):** Agent จะเป็นคนอ่านข้อมูลทั้งหมดในหมวดที่ 1–8 แล้วสังเคราะห์เขียนออกมาให้เองโดยอัตโนมัติ

## 🧠 หมวดที่ 4: โครงสร้างจิตวิทยาเชิงลึก (Psychological Profile & AI Probability Engine)

> *(หากเว้นว่างไว้ Agent จะคำนวณความน่าจะเป็นจากหมวดอื่นแล้วเติมตารางวิเคราะห์ด้านล่างให้)*

### 4.1 พิมพ์เขียวบุคลิกภาพ (Personality Typology)
- **MBTI Type:** `[เช่น INTJ / INFP / ENTP]`
  - **Cognitive Functions:**
    1. *Dominant (ฟังก์ชันหลักที่ใช้ตลอดเวลา):* `[เช่น Ni / Ti / Fi]` — [อธิบายวิธีคิด]
    2. *Auxiliary (ฟังก์ชันเสริมเวลาแก้ปัญหา/เข้าสังคม):* `[เช่น Te / Ne / Fe]` — [อธิบายวิธีแสดงออก]
    3. *Tertiary (ฟังก์ชันที่โผล่มาเวลาสบายใจหรือดื้อเงียบ):* `[เช่น Fi / Si]` — [อธิบาย]
    4. *Inferior (จุดเปราะบาง/ฟังก์ชันที่หลุดออกมาเวลาเครียดสุดขีด):* `[เช่น Se / Fe / Te]` — [อธิบาย]
- **Enneagram (นพลักษณ์):** `[เช่น 1w9 / 4w5 / 6w5]`
  - **Instinctual Variant (สัญชาตญาณย่อย):** `[เช่น sp/sx (Self-Preservation / One-to-One)]`
  - **แรงจูงใจหลักตามลักษณ์ (Core Desire):** [ต้องการอะไรเพื่อให้รู้สึกปลอดภัย/มีคุณค่า]
  - **ความกลัวหลักตามลักษณ์ (Core Fear):** [กลัวอะไรมากที่สุดในชีวิต]
  - **📉 ทิศทางเมื่อความเครียดพุ่งสูง (Stress / Disintegration Arrow -> เชื่อมกับค่า `Stress` ในเกม):**
    - *เคลื่อนไปสู่ลักษณ์ `[X]`:* [พฤติกรรมเวลาสติแตกหรือหมดไฟ เช่น กลายเป็นคนเก็บตัว ตัดพ้อ หรือควบคุมทุกอย่างเกินเหตุ]
  - **📈 ทิศทางเมื่อรู้สึกปลอดภัยและมีความรัก (Growth / Integration Arrow -> เชื่อมกับค่า `Affection` ในเกม):**
    - *เคลื่อนไปสู่ลักษณ์ `[Y]`:* [พฤติกรรมเวลาคลายกำแพงในใจ เช่น ผ่อนคลาย ขี้เล่น กล้าพึ่งพาผู้เล่น]

### 4.2 จิตวิทยาความรักและความผูกพัน (Romantic Psychology)
- **Attachment Style (รูปแบบความผูกพัน):** `[เลือก: Secure / Anxious-Preoccupied / Dismissive-Avoidant / Fearful-Avoidant]`
  - *คำอธิบายท่าทีในความรัก:* [เช่น อยากใกล้ชิดแต่พอก้าวเข้ามาใกล้จริงๆ กลับกลัวและถอยหนี]
