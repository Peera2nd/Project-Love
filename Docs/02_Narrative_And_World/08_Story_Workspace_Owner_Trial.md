# ลอง Story Workspace — เขียนบทและตรวจลอจิกในหน้าต่างเดียว

Session 071 · 27 ตุลาคม 2026 · แทนคู่มือปุ่มรุ่น Session 069

เปิด Unity โปรเจกต์ `.sandbox/StoryWorkspaceProject` แล้วเลือก **Project Love > Story Workspace** รุ่นนี้แก้บทและลอจิกบนสำเนาในหน้าต่างเดียว ชื่อปุ่มเป็นอังกฤษ ส่วนเนื้อเรื่องยังเป็นไทย เอาเมาส์ค้างที่หัวข้อหรือปุ่มเพื่ออ่าน tooltip ได้ ไม่ต้องเปิดเครื่องมือเขียนบทเดิม

## เริ่มเขียนฉากใหม่

1. กด **New Scene** จะได้ฉาก Draft ที่ยังไม่เปิดใช้ เขียนชื่อใน **Inspect > Name**
2. พิมพ์บทลงการ์ด เลือกผู้พูดและสีหน้า **Narrator** คือคำบรรยาย สลับ **TH / EN** เพื่อแก้ภาษา
3. กด **+ Line** หรือคลิกช่องว่างระหว่างการ์ดเพื่อแทรกบรรทัด จับที่หูจับด้านซ้ายเพื่อลากบทพูดไปช่องว่างในช่วงอื่น หรือใช้ลูกศรขึ้น/ลง
4. **+ Block** แทรกช่วงใหม่ก่อนทางไปต่อเดิม ส่วน **+ Choice** เพิ่มตัวเลือก, **+ Reply** สร้างช่วงคำตอบ และ **Link** เลือกปลายทางด้วยการค้น **End** คือจบการสนทนานั้น
5. ตั้ง **Trigger**, วัน/เวลา/ห้อง และ **Conditions** ใน Inspect แล้วเปิด **Enabled** เมื่อเขียนครบ **Auto** ให้เกมเรียกเมื่อผ่านเงื่อนไขและว่าง, **Character** ผ่านบับเบิลตัวละคร, **Manual** ต้องมีระบบ/การกระทำเรียก
6. กด **Validate** แล้วแก้ปัญหาที่แจ้ง จากนั้น **Save** ลองปิดและเปิดหน้าต่างใหม่เพื่อตรวจว่างานยังอยู่

การ์ดที่ลากคือบทพูดภายในช่วงหรือข้ามช่วง ทางแยกและจุดรวมยังเชื่อมด้วย Link การแก้ช่วงที่ขึ้น **Shared** กระทบทุกที่ที่ใช้ช่วงนั้น ดู **Flow > Used By** ก่อนแก้หากไม่แน่ใจ Undo/Redo รองรับการแก้และย้ายการ์ด

## เลือกตอบแล้วเกมจำอะไร

ลองฉาก **วันแรก · สารภาพรัก หรือสมัครงาน**:

1. เปิด **Test** ตั้ง Day 1 / Morning แล้วกด **Run Caller** เพื่อใช้เงื่อนไขและระบบเรียกจริง
2. กด **Next Line** จนถึงสามทางเลือก แล้วเลือกคำตอบหนึ่ง
3. เปิด **State > Flags** ดูธงที่ตั้ง และ **State > History** ดูประวัติคำตอบที่เลือก (รหัสอยู่ใน tooltip)
4. เปิด **Trace** ดูว่าแต่ละการกดเปลี่ยนอะไร ก่อน/หลังเป็นค่าไหน
5. กลับ Test แล้วอ่านจนจบฉาก จากนั้นดู History อีกครั้ง จะเห็นเหตุการณ์ที่เพิ่งจบ ต่างจากการเลือกตอบซึ่งเก็บทันที

ตัวอย่างคำตอบ “ลองพูดตรงๆ ว่าอยากเจอกันอีก” ตั้งธง `opening_advice_direct` และเก็บรหัสตัวเลือกเดียวกัน ถ้าจะให้เหตุการณ์ถัดไปจำคำตอบนี้ ต้องตั้ง **Conditions > Flag Set** เป็นธงนี้ ประวัติการกดตอบไม่ได้สร้างเงื่อนไขให้เองทุกชนิด

หากต้องการให้ตัวเลือกใหม่มีผล ให้เลือกการ์ด **Choice** แล้วแก้ **Inspect > Results** เพิ่ม **+ Flag** หรือ **+ Value** ได้ ส่วนเงื่อนไขว่าจะกดตัวเลือกนี้ได้หรือไม่อยู่ใน **Conditions** ของตัวเลือกนั้น

ผลบางชนิดเกิดเมื่อจบกิจกรรม เช่น รางวัลคุยเล่น/ทำงานด้วยกัน ไม่ใช่ทุกอย่างเปลี่ยนตอนกดตัวเลือก Trace จะแสดงการเปลี่ยนจากระบบจริง และ **Defer** จะย้อนค่าตาม snapshot ของการสนทนานั้น

## ไล่ดูว่าทำไมบทถึงเกิด

- **Inspect:** วิธีเรียก วัน/เวลา/ห้อง Priority เงื่อนไข และผลเมื่อจบ
- **Flow:** ต้นทางทุกทาง ปลายทางแต่ละตัวเลือก จุดรวม Used By และ Variables ที่อ่าน/เขียนธงเดียวกัน
- **Test:** ทดลองบริบทจริง ดูเครื่องหมายผ่าน/ไม่ผ่านและเอาเมาส์จ่ออ่านรายละเอียด หากมี **Pending** แปลว่ามีอีเว้นอัตโนมัติรอก่อน
- **State:** ค่าของ session ทดลองปัจจุบัน ไม่ใช่เซฟจริง
- **Trace:** การเรียกและการเปลี่ยนค่าแต่ละครั้ง ไม่ต้องเดาจากคำอธิบายบท

ระหว่างอ่านบทเดียวกัน เกมเดินบรรทัดตามลำดับและลิงก์ ไม่ได้เลือกอีเว้นใหม่ทุกประโยค เงื่อนไขหลักอยู่ที่ทางเข้า/ตัวเลือก และระบบเลือกบททักทายหรือคุยเล่น

**Run Caller** ตรวจการเข้าถึงจริง ส่วน **Preview Block** ข้ามเงื่อนไขเพื่อดูงานเขียนตรงช่วงที่เลือก อย่าใช้ Preview Block เป็นหลักฐานว่าบทเกิดได้จริง เมื่อเปลี่ยนข้อมูลเขียนบทหรือบริบท ต้องเริ่ม Test ใหม่ **Next Event** เรียกตัวเลือกอัตโนมัติถัดไปผ่าน scheduler จริง

## ขอบเขตการบันทึก

Save เก็บสำเนาใน `Assets/_Project/StorySandboxDrafts/Workspace.asset` ภายในโปรเจกต์ทดลอง ไม่มีปุ่มนำไปทับเกมจริง ฉบับ TextDraft เดิมยังเก็บไว้และนำเข้าครั้งแรกเท่านั้น ก่อนลบ/แทนโฟลเดอร์ทดลองให้สำรอง StorySandboxDrafts ทั้งโฟลเดอร์

ต้นแบบยังไม่จำลองการให้ของขวัญพร้อม inventory, ไม่โหลดเซฟผู้เล่นมา Test และยังไม่มีระบบเสียงใหม่ การย้ายระบบเข้าเกมจริงต้องรอการยอมรับ UX แยกต่างหาก
