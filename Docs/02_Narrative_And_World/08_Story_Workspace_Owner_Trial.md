# ลองใช้งานหน้ารวมบท — รอบทดสอบของผู้เขียน

Session 070 · 27 ตุลาคม 2026 · คู่มือสำหรับต้นแบบ Story Workspace จาก Session 069

รอบนี้ลองในโปรเจกต์ **StoryWorkspaceProject** ใช้เวลาประมาณ 20–30 นาทีได้ โดยไม่ต้องไล่เปิดไฟล์ SO เป้าหมายคือดูว่าหาบท อ่านเรื่องต่อเนื่อง และแก้แล้วมั่นใจได้หรือไม่ ไม่ใช่ตรวจว่าปุ่มกดติดอย่างเดียว ผลการลองของคุณยังไม่ได้ถูกบันทึกว่า “ผ่าน”

## เปิดให้ถูกโปรเจกต์

1. เปิดโปรเจกต์ `.sandbox/StoryWorkspaceProject` ผ่าน Unity Hub โดยใช้ Unity `6000.3.24f1` โฟลเดอร์นี้อยู่ใต้โฟลเดอร์งาน `Visual Novel` อย่าใช้โปรเจกต์เกมจริง `Project Love` สำหรับรอบนี้
2. ใน Unity เลือก **Project Love > ทดลองหน้ารวมบท (Sandbox)** หากต้องการคำอธิบายสั้น กด **วิธีลองใช้งาน** ด้านบน
3. ถ้ายังไม่มีโฟลเดอร์ทดลอง ให้ใช้ตัวเปิด [Open-StorySandbox.ps1](../../Sandbox/StoryWorkspace/Open-StorySandbox.ps1) ตาม [คู่มือต้นแบบ](../../Sandbox/StoryWorkspace/README.md) ซึ่งสร้างสำเนาครั้งแรก และรักษาฉบับทดลองเดิมในการเปิดครั้งถัดไป

ไม่มีปุ่มนำข้อความกลับเข้าเกมจริงในต้นแบบนี้ ข้อความที่แก้และบันทึกอยู่ในโปรเจกต์ทดลอง หากจะลบโฟลเดอร์ทดลอง ให้เก็บสำรอง `Assets/_Project/StorySandboxDrafts` ภายในโปรเจกต์นั้นก่อน

## 1. อ่านฉากเปิดเรื่องให้รู้เรื่อง โดยไม่เปิดไฟล์อื่น

เริ่มจาก **วันแรก · สารภาพรัก หรือสมัครงาน** ตรงกลางควรอ่านได้ตั้งแต่คำบรรยายต้นฉาก ผ่านบทพูดสลับกันของเกรซ พลอย และปลายฟ้า รวมแปดบรรทัดก่อนมีทางเลือก

- ลองอ่านจากบนลงล่าง: แยกได้ทันทีไหมว่าบรรทัดไหนใครพูด และอยู่ในฉากอะไร
- เลื่อนลงอ่านทั้งสามทางเลือกและคำตอบของแต่ละทาง
- เมื่อพบ **↪ จุดรวม / ย้อนกลับ** ลองกดเพื่ออ่านช่วงที่แขนงกลับมารวมกัน
- ถ้าไม่ชัดว่าทางไหนต่อจากทางไหน ให้จดตรงนั้นไว้ได้เลย ไม่ต้องพยายามตีความแทนเครื่องมือ

หน้าบทแสดงทุกแขนงที่เป็นไปได้เพื่อให้อ่านเรื่อง ไม่ได้บอกว่าทุกทางเลือกผ่านเงื่อนไขในเซฟใดเซฟหนึ่ง

## 2. หาประโยคที่จำได้ และหาฉากจากผู้พูด

ลองสองแบบแยกกัน:

1. พิมพ์ **ความสัมพันธ์ระยะยาว** ในช่องค้นหาด้านซ้าย เลือกผลประโยคของเกรซ แล้วดูบรรทัดก่อนและหลังประโยคนั้นให้รู้ว่าอยู่ในเหตุการณ์ไหน
2. ล้างคำค้น เลือก **มีผู้พูด > ปลายฟ้า** แล้วเลือกฉากหนึ่งที่มีเธอพูด โดยไม่ใช้ชื่อไฟล์ หากต้องการลองช่วงวัน/เวลา ให้เปิด **กรองช่วงวัน / เวลา** เพิ่มภายหลัง

ตัวกรองผู้พูดรวมตัวละครที่พูดในแขนงต่าง ๆ ของบริบทนั้น จึงยังอาจเห็นบทของคนอื่นในฉากเดียวกันได้ ตัวกรองวัน/เวลาตรวจช่วงที่ผู้เขียนกำหนดไว้เท่านั้น ไม่ได้ตรวจทุกธง/เหตุการณ์แทนตัวลองบริบท

ลองสังเกตว่าผลการค้นมีข้อมูลพอเลือกได้หรือไม่ ถ้าหาไม่เจอ ให้ดูว่ามีตัวกรองเก่าค้างอยู่หรือเปล่า และจดด้วยว่ามันเห็นชัดพอไหม

## 3. ย้อนต้นทางและดูปลายทาง

กลับมาฉากเปิดเรื่อง กดหัวข้อช่วงที่เป็นจุดรวมหลังสามทางเลือก แล้วดูด้านขวา:

- **ต้นทางโดยตรง:** เห็นและกดย้อนกลับไปช่วงคำตอบทั้งสามได้หรือไม่
- **ไปต่อ / แต่ละทางเลือก:** เมื่อเลือกช่วงต้นเรื่อง เห็นข้อความของตัวเลือก ปลายทาง และตัวอย่างคำตอบแรกหรือไม่
- **ถูกใช้ในบริบทใดบ้าง:** รู้ได้หรือไม่ว่าบทนี้ถูกเรียกใช้จากเหตุการณ์หรือบริบทใด
- ขยาย **เส้นทางจากต้นเรื่องถึงช่วงนี้ (ทุกทาง)** เพื่อดูเงื่อนไขตามเส้นทาง ไม่ควรเข้าใจผิดว่าต้องผ่านทุกแขนงพร้อมกัน
- ใช้ลูกศร **← / →** ข้างหัวข้อบทเรียงต่อเนื่อง แล้วดูว่ากลับไปตำแหน่งที่คาดหวังหรือไม่

คำว่า **จบบท** หมายถึงจบการสนทนานั้น ไม่ใช่จบเกมทั้งเกม ในบางบริบทอาจไม่มีเงื่อนไขเสริมจริง ไม่จำเป็นต้องมีเงื่อนไขทุกประโยค

## 4. แก้หนึ่งประโยค ย้อนกลับ และบันทึก

1. กดประโยคของเกรซในต้นฉาก ด้านขวาควรมี **แก้เฉพาะฉบับทดลอง** พร้อมช่องไทยและ English
2. เติมคำว่า `[ทดสอบ]` ต่อท้ายข้อความไทย ลองย้อนด้วย **Ctrl+Z** และทำซ้ำด้วย **Ctrl+Y** ดูว่าข้อความตรงกลางเปลี่ยนตามด้วยหรือไม่
3. ใส่หรือแก้ประโยคอังกฤษสั้น ๆ หนึ่งประโยค แล้วกด **บันทึกฉบับทดลอง** ด้านบน
4. ไปอ่านฉากอื่น แล้วกลับมาหาประโยคเดิม
5. ปิดเฉพาะหน้าทดลอง แล้วเปิดจากเมนูเดิมอีกครั้ง ข้อความที่บันทึกควรยังอยู่

ลองสังเกตว่ารู้ชัดไหมว่าแก้ประโยคไหน กำลังแก้ไทยหรืออังกฤษ มีอะไรยังไม่บันทึก และข้อมูลจะไปอยู่ที่ไหน หาก Undo ทำงานไม่ตรงที่คิด ให้บอกว่าตอนนั้นเคอร์เซอร์อยู่ช่องใด ไม่ต้องแก้ไฟล์ด้วยมือ

เมื่อทดสอบเสร็จจะลบ `[ทดสอบ]` แล้วบันทึกคืนก็ได้ หรือเก็บไว้ให้เห็นตำแหน่งที่ลอง ไม่มีผลกับข้อความเกมจริง

## 5. ดูสิ่งที่แก้ในหน้าจอเกม

1. เลือกช่วงบทที่มีประโยคที่แก้
2. เลื่อนแผงด้านขวาลงถึง **ตัวอย่างเกมจากฉบับทดลอง** แล้วกด **เปิด / เริ่มตัวอย่างช่วงนี้ใหม่**
3. กด **อ่านต่อ** จนถึงประโยคที่แก้ แล้วลองหนึ่งทางเลือก
4. หากจะดูอังกฤษ ให้เปิด **แสดงอังกฤษ** ด้านบน แล้วกด **เปิด / เริ่มตัวอย่างช่วงนี้ใหม่** อีกครั้ง ต้นแบบปัจจุบันสร้างตัวอย่างด้วยภาษาที่เลือกตอนเริ่ม ไม่ได้เปลี่ยนภาษาตัวอย่างเดิมทันที

ตัวอย่างเริ่มตรงช่วงที่เลือก โดยข้ามเงื่อนไขเข้าถึง เพื่อให้เช็กงานเขียนและหน้าจอได้เร็ว ไม่ใช่การเริ่มเล่นจากเซฟจริง หากไม่มีคำแปลอังกฤษ ระบบยังใช้ภาษาไทยสำรองได้ การแก้ข้อความหรือ Undo อาจปิดตัวอย่างเดิม ให้เริ่มตัวอย่างใหม่เพื่ออ่านฉบับล่าสุด

รอบนี้ยังไม่มีระบบเลือก/เล่นเพลง เสียงเอฟเฟกต์ หรือเสียงพูดใหม่ ปุ่มและภาพตัวอย่างระบบเสียงในเอกสารแผนเป็นข้อเสนอเท่านั้น

## 6. ลองเหตุผลว่าเข้าถึงบทได้หรือไม่ได้ — ถ้ายังมีเวลา

เลือกบริบทอีเว้นเปิดเรื่อง แล้วดู **ลองบริบทด้วยระบบเลือกบทจริง** ลองวันที่ 1 ช่วงเช้าก่อน จากนั้นเปลี่ยนเป็นวันที่ 2 แล้วกด **ตรวจการเข้าถึงในบริบทนี้** ดูว่าอ่านเหตุผลว่าติดอะไรได้หรือไม่

ตัวลองสร้างสถานะใหม่ตามข้อมูลเริ่มต้นของเกม ไม่ใช้เซฟผู้เล่น ห้อง/งานและสถานะอื่นที่ไม่ได้เปิดให้แก้ยังเป็นค่าเริ่มต้นของเกม รอบแรกเว้นช่องธงและอีเว้นที่จบไว้ได้ ไม่จำเป็นต้องจำรหัสเพื่อทดสอบงานค้นหาและอ่านบท
