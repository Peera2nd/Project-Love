# ไอเดียอีเว้นสตูดิโอ

บันทึก Session 022 — ยังเป็นไอเดียสำหรับคุยและทดลอง ไม่ใช่บทที่อนุมัติแล้วหรืออีเว้นที่ใส่ในเกมแล้ว

## เกรซป่วยระหว่างช่วงท้ายของโปรเจค

ไอเดียจากผู้ใช้: ตั้งแต่ประมาณวันที่ 20 เป็นต้นไป หากงานหลักใกล้เต็ม เกรซอาจป่วยและทำงานไม่ได้ 3 วัน เกิดโจทย์การรับมืองาน Code พร้อมโอกาสได้ใกล้ชิดและเห็นด้านอ่อนไหวของเกรซ

สิ่งที่อีเว้นควรทำให้รู้สึก: ทีมมีชีวิตนอกเหนือจากแถบความคืบหน้า ผู้เล่นต้องตัดสินใจทั้งในฐานะ Producer และคนที่ห่วงใยเกรซ การดูแลเธอมีความหมายโดยไม่ต้องบังคับให้ผู้เล่นเลือกทำงานแทนการเป็นห่วงเสมอไป

ข้อเสนอที่ยังต้องคุย:

- ปูสัญญาณล่วงหน้าให้เหตุการณ์มีที่มา และให้ผู้เล่นเห็นช่วงที่กำลังคนจะหายไป
- วันที่เริ่ม ช่วงเวลาที่อีเว้นเกิดได้ และเงื่อนไขความสนิท ยังไม่ล็อก ไม่จำเป็นต้องเกิดทันทีเมื่อแถบงานสูง
- ให้มีทางจัดการงานค้าง เช่น ปรับลำดับ ลดขอบเขต ขอความช่วยเหลือ หรือใช้เวลาสำรอง ไม่ทำให้การพลาดเล็กน้อยก่อนหน้ากลายเป็นแพ้แน่นอน
- โอกาสเห็นด้านอ่อนไหวของเกรซไม่ควรถูกจำกัดเฉพาะคนที่ทำงานได้ดีมากเท่านั้น อาจใช้บริบทหรือผลลัพธ์ต่างกันได้
- อาการป่วย ระดับความหนัก บทพูด และฉากดูแล ยังไม่กำหนด

กติกางานและระบบอยู่ใน [Studio Work and Sprints](../01_Game_Design/03_Studio_Work_And_Sprints.md) ส่วนบทพูดคุยและของขวัญที่ใส่ในต้นแบบเป็นข้อความทดสอบ ไม่ใช่การล็อกพล็อตหรือรสนิยมใหม่ของตัวละคร
